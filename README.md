A tiny deterministic program that writes one funny excuse from a robot vacuum for missing a spot — 140 characters or fewer — to `/output/entry.txt`. Built for make.fun's "The Robot Vacuum's Best Excuse" bounty.

## Run it

```sh
node main.ts
```

This writes the excuse to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Node 22, standard library only, no network, no randomness.
